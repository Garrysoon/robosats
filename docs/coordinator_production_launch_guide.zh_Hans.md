## 0. ⚡ 一键极速部署（Quickstart）

为了使协调者能够在几分钟内就绪上线，系统提供了全自动安装向导：

### 选项 A：跨平台 Python 全自动向导
```bash
# 启动交互式安装向导并完成系统自检：
python setup_coordinator.py

# 或使用默认参数一键快速启动：
python setup_coordinator.py --quick
```

向导将自动执行：
- 随机生成高强度密码学密钥 `SECRET_KEY` 与 `FERNET_PREIMAGE_KEY`。
- 自动写入生产配置文件 `.env`。
- 执行数据库迁移与初始化。
- 编译多语言本地化语言包（.mo）。
- 创建超级管理员账户 `admin` 并输出控制台直达链接。

### 选项 B：Windows 桌面一键启动
在电脑桌面上直接双击 **「RoboSats 协调者」** 快捷方式（或运行 `start_coordinator.bat`）。脚本将自动校验环境并在 2 秒后唤起浏览器进入后台管理控制台：
- **控制台地址：** `http://127.0.0.1:8000/coordinator/`
- **默认用户：** `admin`
- **默认密码：** `admin12345`

### 选项 C：热备与故障转移（Failover）
- **一键热备导出：** 运行 `export_standby.bat` 生成便携数据包。
- **自动心跳哨兵：** 在备用机运行 `start_watchdog.bat`。一旦主机网络中断或宕机超过 3 次检测，备用机将自动接管服务并发布相同的 Tor 地址！

## 1. 系统架构与运行环境要求

RoboSats 协调者由以下高可用服务构成：
- **Web 应用引擎：** Django 4.2 + Channels（WebSocket 双向实时通信）。
- **异步任务队列：** Celery + Redis 7。
- **关系型数据库：** PostgreSQL 15（生产模式）或 SQLite 3（轻量单机模式）。
- **隐私暗网协议：** Tor Onion v3（提供 56 字符专属不可篡改的 `.onion` 静态服务地址）。
- **闪电网络基础设施：** LND 0.17+ 或 Umbrel Lightning Node。

## 2. 争议仲裁控制台（Dispute Cockpit）实操流程

1. **进入专属争议页面：**
   通过左侧菜单点击 **「🚨 仲裁与争议 $\rightarrow$ 争议与订单」**。页面已自动过滤处于争议审查中的订单。
2. **双通道独立隐私沟通：**
   协调者与挂单方（Maker）和吃单方（Taker）的沟通各自隔离在独立频道中，双方无法窥探对方提交的聊天内容与证据。
3. **银行数字签名校验（DKIM）：**
   系统自动解析银行邮件中的 RSA-SHA256 签名，核对转账附言中的防三角诈骗验证码（`ROBO-...`）与订单金额。
4. **一键裁决（1-Click Verdict）：**
   点击对应按钮：
   - **判定买方胜诉**（释放比特币给买方并退还其保证金）
   - **判定卖方胜诉**（扣除违约方押金）
   - **协商退款**（全额退还双方质押金）
