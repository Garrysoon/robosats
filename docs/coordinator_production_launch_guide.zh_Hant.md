## 0. ⚡ 一鍵極速部署（Quickstart）

為了使協調者能夠在幾分鐘內就緒上線，系統提供了全自動安裝精靈：

### 選項 A：跨平台 Python 全自動精靈
```bash
# 啟動互動式安裝精靈並完成系統自檢：
python setup_coordinator.py

# 或使用默認參數一鍵快速啟動：
python setup_coordinator.py --quick
```

精靈將自動執行：
- 隨機生成高強度密碼學密鑰 `SECRET_KEY` 與 `FERNET_PREIMAGE_KEY`。
- 自動寫入生產配置文件 `.env`。
- 執行數據庫遷移與初始化。
- 編譯多語言本地化語言包（.mo）。
- 創建超級管理員賬戶 `admin` 並輸出控制台直達鏈接。

### 選項 B：Windows 桌面一鍵啟動
在電腦桌面上直接雙擊 **「RoboSats 協調者」** 快捷方式（或運行 `start_coordinator.bat`）。腳本將自動校驗環境並在 2 秒後喚起瀏覽器進入後台管理控制台：
- **控制台地址：** `http://127.0.0.1:8000/coordinator/`
- **默認用戶：** `admin`
- **默認密碼：** `admin12345`

### 選項 C：熱備與故障轉移（Failover）
- **一鍵熱備匯出：** 運行 `export_standby.bat` 生成便攜數據包。
- **自動心跳哨兵：** 在備用機運行 `start_watchdog.bat`。一旦主機網絡中斷或當機超過 3 次檢測，備用機將自動接管服務並發布相同的 Tor 地址！

## 1. 爭議仲裁控制台（Dispute Cockpit）實操流程

1. **進入專屬爭議頁面：**
   通過左側菜單點擊 **「🚨 仲裁與爭議 $\rightarrow$ 爭議與訂單」**。頁面已自動過濾處於爭議審查中的訂單。
2. **雙通道獨立隱私溝通：**
   協調者與掛單方（Maker）和吃單方（Taker）的溝通各自隔離在獨立頻道中，雙方無法窺探對方提交的聊天內容與證據。
3. **銀行數位簽名校驗（DKIM）：**
   系統自動解析銀行郵件中的 RSA-SHA256 簽名，核對轉賬附言中的防三角詐騙驗證碼（`ROBO-...`）與訂單金額。
4. **一鍵裁決（1-Click Verdict）：**
   點擊對應按鈕：
   - **判定買方勝訴**（釋放比特幣給買方並退還其保證金）
   - **判定賣方勝訴**（扣除違約方押金）
   - **協商退款**（全額退還雙方質押金）
